# Module 2: Get your own copy of this course
`🟢 Easy` · 10 min

You'll practise on **your own copy** of this course on GitHub, so you're free to branch, commit and open pull requests without affecting anyone else. Then you'll **clone** it: download it to your computer so you can work on it.

## Step 1: Put the course on your GitHub account

Pick the option that matches how you got the course.

**A. You were given a GitHub link to the course**
1. Open the link while signed in to GitHub.
2. If you see a green **Use this template** button: click it → **Create a new repository**. Otherwise click **Fork**.
3. **Owner:** you. **Name:** `AI-Starter-Training`. Choose **Private**. Click **Create**.
4. Then clone it with GitHub Desktop: **File → Clone repository…** → **GitHub.com** tab → choose `<your-username>/AI-Starter-Training` → pick a local path such as `Documents\GitHub\AI-Starter-Training` → **Clone**.

**B. You were given the course as a folder or zip file**
1. Unzip it (if needed) to somewhere like `Documents\GitHub\AI-Starter-Training`.
2. In GitHub Desktop: **File → Add local repository…** → choose that folder.
3. It says *"This directory does not appear to be a Git repository"*. Click **create a repository**, then **Create repository**.
4. If the **Changes** tab lists files, write the summary `Add course files` and click **Commit to main**.
5. Click **Publish repository**, keep **Keep this code private** ✅ ticked, and click **Publish repository**.

Either way, GitHub Desktop now shows **Current repository: AI-Starter-Training** and **Current branch: main**. Remember which folder it's in.

## Or ask your AI agent

> I have the AI Starter Training course at <link or folder>. Put a private copy of it on my personal GitHub account called AI-Starter-Training, and make sure it's cloned to my Documents\GitHub folder.

(In the Claude desktop app, open the Code tab and choose the folder first.)

## Have a look around

In GitHub Desktop: **Repository → Show in Explorer** (Windows) or **Show in Finder** (Mac). You'll see `README.md`, `modules/` and `projects/`.

Open `projects/_example-split-bill/index.html` in your web browser. That's the kind of thing you'll build.

- **No Fork or Use this template button:** you may not have access to the original. Ask whoever shared it for a zip instead, and use option B.
- **"Authentication failed":** in GitHub Desktop, File → Options (Windows) / Settings (Mac) → Accounts → sign out and back in.
