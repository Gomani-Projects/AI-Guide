# Module 1: Install your tools
`🟢 Easy` · 15 min

You need two things: **GitHub Desktop** (to move your work to and from GitHub) and **an AI coding agent** (to help you build).

## Step 1: Install GitHub Desktop

1. Download from <https://desktop.github.com/> and install.
2. Open it and choose **Sign in to GitHub.com**. Your browser opens; approve the sign-in.
3. When asked to **Configure Git**, use your name and choose your GitHub email (the `...@users.noreply.github.com` option keeps your real email private).

GitHub Desktop also installs Git for you.

## Step 2: Choose an AI coding agent

Pick **one**. You can try others later.

| Agent | Level | Good for | Get it |
|---|---|---|---|
| **Claude desktop app** (Code tab) | 🟢 Easy | Beginners. Chat plus an agent that can build in a folder, run your app and use Git for you. **Recommended for this course.** | <https://claude.ai/download> |
| **VS Code + GitHub Copilot** | 🟡 Moderate | People who want to see and edit the code in an editor | [VS Code](https://code.visualstudio.com/), then the Copilot extension |
| **VS Code + Claude Code extension** | 🟡 Moderate | Same as above, using Claude | [VS Code](https://code.visualstudio.com/), then the "Claude Code" extension |
| **Cursor** | 🟡 Moderate | An editor with AI built in | <https://cursor.com> |
| **Claude Code CLI** | 🔴 Hard | Terminal users who want the most control | <https://claude.com/claude-code> |

Install your choice and sign in. Most need a paid plan (or a work licence, if your employer provides one).

## Step 3: Say hello

Open your AI agent and type:

> Hi! I'm about to learn how to build a small app with you. In two sentences, what can you help me with?

If it answers, you're set up.

## ✅ Checkpoint

- [ ] GitHub Desktop is installed and signed in
- [ ] My AI coding agent is installed and answered me

<details>
<summary>If something goes wrong</summary>

- **Can't install software:** on a work computer you may need IT approval. Ask IT to install GitHub Desktop and your chosen agent.
- **GitHub Desktop sign-in loops:** sign in to github.com in your normal browser first, then retry.
- **AI tool says no access / no credits:** you need an account with a plan. Check the tool's pricing page.
</details>
