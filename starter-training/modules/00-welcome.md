# Module 0: Welcome
`🟢 Easy` · 5 min

## What you'll end up with

- An AI coding agent and GitHub Desktop installed and working
- A small app, game or tool **you** designed and built with AI
- A **branch** and a **draft pull request** in your copy of this course showing your work
- A separate **personal repo** on GitHub holding your app

## The five ideas you need

| Idea | Plain English |
|---|---|
| **Repository (repo)** | A project folder plus its full history, stored on GitHub |
| **Clone** | Download a copy of a repo to your computer |
| **Branch** | Your own copy of the project to work in without affecting anyone else |
| **Commit** | A saved snapshot of your changes, with a short message |
| **Pull request (PR)** | "Here are my changes, please take a look." Where review happens. |

```
main      ──●─────────────────────────────  (off-limits: the clean course)
             \
your branch   ●──●──●── Draft Pull Request  (your app, reviewed but never merged)
```

## Before you start

- You need a free **GitHub account**. Not yet? See [the setup section of the guide](../../guide/README.md#4-create-your-github-account).
- A Windows or Mac computer where you can install apps. (On a work computer, check with IT if you're unsure.)
- About 1–2 hours. You can stop between modules and come back.

## Rules for the course

1. Only add files inside `projects/<your-github-username>/`.
2. No passwords, API keys, customer or personal data. Ever.
3. Read what the AI asks permission to do before you click "allow".
4. Stuck? That's normal. Check the "If something goes wrong" box at the end of each module, or ask your AI agent: *"I'm stuck on this step: … Explain what's wrong in plain English."*
