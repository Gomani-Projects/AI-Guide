# Module 3: Create your branch
`🟢 Easy` · 5 min

`main` is off-limits, so all your work happens on **your own branch**. A branch is a parallel copy where you can change anything without affecting anyone else.

## Name your branch

Use: `training/<your-github-username>`, e.g. `training/jsmith`

## With GitHub Desktop

1. Make sure **Current branch** says `main`, then click **Fetch origin** (top right) to get the latest version.
2. Click **Current branch → New branch**.
3. Type `training/<your-github-username>` and click **Create branch**.
4. Click **Publish branch**. This puts your (still empty) branch on GitHub.

## Or ask your AI agent

> In this repo, switch to main, pull the latest changes, then create and publish a branch called training/<your-github-username>.

## Create your project folder

Inside the repo, make a folder: `projects/<your-github-username>/`

(Explorer/Finder → open `projects` → New folder. Or ask your AI: *"Create the folder projects/<my-username>."*)

This folder is yours. Everything you build goes in here.

## ✅ Checkpoint

- [ ] GitHub Desktop shows **Current branch: training/<my-username>**
- [ ] My folder `projects/<my-username>/` exists

<details>
<summary>If something goes wrong</summary>

- **Made changes on `main` by accident:** GitHub Desktop will offer to **bring your changes** to the new branch when you create it. Choose that.
- **Branch name already exists:** add a number, e.g. `training/jsmith-2`.
</details>
