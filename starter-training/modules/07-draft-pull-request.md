# Module 7: Open a draft pull request
`🟢 Easy` · 10 min

A **pull request (PR)** says: *"Here are my changes, please review them."* A **draft** PR says: *"Work in progress, feel free to look, but not ready to merge."*

Your PR will **never be merged**: nothing goes into `main`. That's the point. It's where you (or a friend, mentor or teammate you invite) can see your work and leave feedback.

## With GitHub Desktop

1. Click **Preview Pull Request** (or **Branch → Create Pull Request**). Your browser opens on GitHub.
2. Check the top shows **base: `main`** ← **compare: `training/<your-username>`**.
3. **Title:** `Training: <your name>: <your app name>`
4. The **description** is pre-filled with a checklist. Fill it in and tick the boxes (change `[ ]` to `[x]`).
5. Click the **arrow next to "Create pull request"** → choose **Create draft pull request** → click it.

## Or ask your AI agent

> Open a draft pull request from my branch into main titled "Training: <my name>: <app name>", using the repo's pull request template, and fill in the checklist honestly.

## Explore your PR

On the PR page, look at:
- **Conversation:** description and comments
- **Commits:** your snapshots
- **Files changed:** every line you added. Click the **+** next to a line to leave yourself a comment.

⚠️ **Never click Merge**, and never click **Ready for review** either. Leave it as a draft.

## Share it

Your repo is private, so only people you invite can see it. To get feedback, add someone you trust: repo → **Settings → Collaborators → Add people**, then send them the PR link. They can leave comments or a review.

No one to ask? Ask your AI agent to review the PR instead: *"Review the pull request on my training branch and leave feedback like a friendly mentor."*

If you get feedback, make the change, commit and push again. The PR updates automatically.

## ✅ Checkpoint

- [ ] My draft PR is open with the checklist filled in
- [ ] I looked at the Files changed tab
- [ ] Someone (a person or my AI agent) reviewed it
