# Sample data

`site-production.csv` is **fake** mine-site production data for practising in modules 10, 13 and 14. It's safe to use in any AI tool.

| Column | Meaning |
|---|---|
| `date` | ISO date (YYYY-MM-DD) |
| `site` | Site name |
| `shift` | Day or Night |
| `tonnes` | Tonnes moved |
| `operating_hours` | Hours the equipment operated |
| `equipment_id` | Excavator ID |

It contains a couple of deliberate problems (a missing value and a negative number) for the data-cleaning exercise in Module 13.
